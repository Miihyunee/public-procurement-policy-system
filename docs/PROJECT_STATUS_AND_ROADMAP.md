# 8.2 Dashboard 착수 판단 — **보류**

```text
현재:
Dashboard 실제 구현 보류

이유:
- 실제 운영데이터 미수신
- 업무 매핑 미확정 (지급일·계약일·금액 기준)
- 일부 정책 규칙 미확정 (여성기업·녹색제품·장애인표준사업장·Group C)
- 실제 분모/분자 미확정

착수 가능 시점:
구조 검증 + 업무 매핑 + 최소한의 정책 계산 데이터가 확보된 이후
```

| 구분 | 내용 |
|---|---|
| 이미 있는 것 | `GET /dashboard/summary` (JSON) — 계산 경로는 완성되어 있고 `main` 에 있다 |
| 보류하는 것 | **UI / 화면 / 차트**, 그리고 실제 데이터 기반 결과 표시 |
| 이유 | 지금 만들면 업무 매핑 확정 시 **분모·분자·기준일이 바뀌어 다시 만들게 된다** |

> **UI 프로토타입이 필요하다고 판단되면 지금 구현하지 않고 별도 Phase 로 제안한다.**
> 현재 로드맵에는 포함하지 않았다.
