# 목적

공공기관의 정부권장정책(공공구매) 실적을 자동으로 계산하기 위한 정책 정의 문서이다.

# 정책별 판정 기준 (MVP)

각 정책의 실적 인정 여부는 아래 **판정 기준일**이 해당 기업의 정책 인증
유효기간 내에 있는지로 결정한다. 이 기준일 유형은 Policy.evaluation_basis
컬럼으로 관리한다 (`docs/DATABASE_DESIGN.md` 참조).

| 정책 | 판정 기준일 | evaluation_basis |
|------|-------------|------------------|
| 중소기업 | 대금 지급일 | PAYMENT_DATE |
| 여성기업 | 대금 지급일 | PAYMENT_DATE |
| 장애인기업 | 대금 지급일 | PAYMENT_DATE |
| 창업기업 | 계약일 | CONTRACT_DATE |
| 녹색제품 | 대금 지급일 (기업 기준) | PAYMENT_DATE |

> **MVP 범위 제외 (별도 Issue 로 분리)**
> - 자활용사촌 : 기간 무관·거래 유무·품목 갯수·금액 집계 (기준일 판정과 다른 계산 모델)
> - 녹색제품 제품 단위 판정 : 품목(Item) 데이터 모델 필요

# 공통 계산 원칙

모든 정책은 아래 기준을 따른다.

- 사업자등록번호를 기준으로 기업을 식별한다.
- 정책별 **판정 기준일**을 기준으로 인증 유효 여부를 판단한다.
  (일반 정책 = 대금 지급일, 창업기업 = 계약일. 위 "정책별 판정 기준" 참조)
- 판정 기준일이 인증 유효기간 내에 있는 구매만 인정한다.
  유효기간 경계는 포함(inclusive)한다: `valid_from <= 판정 기준일 <= valid_to`.
- 동일 기업이 같은 정책 인증을 여러 건 보유한 경우, 그중 하나라도 유효기간을 만족하면 인정한다.
- 동일 기업이 여러 정책을 동시에 보유할 수 있다.
- 하나의 구매건은 여러 정책 실적에 동시에 반영될 수 있다.
