# 후속 질문 (2026-08-14 회신에 이어서)

## Q1-1. `결의일자`가 대금 지급 완료일과 같은 날짜입니까? 🔴

> **"구매실적 산정 기준일은 `결의일자`" 로 확인해 주셨습니다.
> 그러면 `결의일자`가 실제로 **대금이 지급 완료된 날**과 같은 것입니까,
> 아니면 지급 완료일과는 다르지만 **실적 산정에는 `결의일자`를 쓰는** 것입니까?**

**왜 필요한가**: 시스템 내부 필드가 "대금 지급일" 이라는 의미로 정의되어 있습니다.
두 날짜가 다른 개념이라면 필드 정의와 문서를 바로잡아야, 나중에 지급일이 별도로
필요해졌을 때 값이 섞이지 않습니다. **계산 결과 자체는 어느 쪽이든 동일합니다.**

## Q2-1. 창업기업 계약일자는 어느 파일에서, 어떤 키로 연결합니까? 🔴

> **① 계약일자가 들어 있는 파일은 무엇입니까? (시스템명 · 파일 형식 · 제공 주기)
> ② 그 파일과 지출데이터를 연결하는 **공통 키**는 무엇입니까?
> (계약번호 · 품의번호 · 결의번호 · 사업자번호 + 금액 등)
> ③ 한 계약에 여러 건의 지출이 발생하는 경우, 어떻게 대응시킵니까?
> ④ 계약일자와 결의일자가 **모두 있을 때**, 창업기업 실적에 포함하는 조건은
> 정확히 무엇입니까? (예: 계약일자만 / 둘 다 해당 연도 / 둘 중 하나라도)**

**왜 필요한가**: 현재 제공된 매입매출장 **88개 컬럼 어디에도 계약 관련 날짜가
없습니다.** 연결 키를 모르면 창업기업 실적을 계산할 수 없습니다.

## Q3-1. 부가세 포함 총액은 어느 컬럼입니까? 🔴

> **"구매금액은 부가가치세 포함 총액" 으로 확인해 주셨습니다.
> 제공해 주신 파일에서 그 총액에 해당하는 컬럼은 `계` 가 맞습니까?
> 실제 운영데이터에도 같은 이름의 컬럼이 있습니까?**

**샘플에서 확인된 상황** (2,903건 전수)

| 컬럼 | 채움률 | 관계 |
|---|---|---|
| `공급가액` | 100% | 부가세 제외 |
| `세액` | 19.3% (나머지 0) | 부가세 |
| **`계`** | **100%** | **`공급가액` + `세액` 전건 일치** |

→ 관계상 `계` 가 VAT 포함 총액으로 보이나, **저희가 확정하지 않았습니다.**
다른 이름의 지급금액 컬럼이 실제 운영데이터에 따로 있을 수 있습니다.

## Q4-1. 음수 거래와 원래 거래를 무엇으로 짝지어야 합니까? 🔴 **가장 시급**

> **"동일 거래의 양수와 상계하여 0원 처리" 로 확인해 주셨습니다.
> 그러면 어떤 거래가 **같은 거래**인지 판단할 때 어느 값을 비교해야 합니까?**

**저희가 확인한 문제 — 샘플에서는 짝지을 수 없습니다.** (음수 125건 전수 조사)

| 후보 컬럼 | 음수 125건 중 채워진 건수 | 판정 |
|---|---|---|
| `기표번호` | **0건** | ❌ 전부 비어 있음 |
| `결의번호` | **0건** | ❌ 전부 비어 있음 |
| `LN_SQ` | **0건** | ❌ 전부 비어 있음 |
| `GRP_NB` | **0건** | ❌ 전부 비어 있음 |
| `사업자번호` | 125건 | ⚠️ 거래처 단위 — 같은 거래처의 다른 거래와 구분 불가 |
| `적요` | 채워짐 | ⚠️ 자유 텍스트 — 동일 문구가 여러 거래에 반복 |

**금액으로도 짝지을 수 없습니다**: 같은 금액이 중복 존재합니다
(`−132,000` 2건, `−200,000` 2건 등). 어느 거래의 취소인지 결정할 수 없습니다.
또한 음수 **24건(19.2%)** 은 같은 사업자에 **금액이 같은 양수 거래가 아예 없습니다.**

**여쭙고 싶은 것**

1. 실제 운영데이터에서는 `결의번호`·`기표번호`가 **음수 행에도 채워집니까?**
2. 채워지지 않는다면, 원거래를 가리키는 **별도의 번호**가 있습니까?
3. 위 24건처럼 대응하는 양수가 없는 음수는 **어떻게 처리해야 합니까?**
4. 상계 대상을 찾는 기간 범위가 있습니까? (예: 같은 연도 안에서만)

> ⛔ 이 답변 전까지 **상계 로직을 만들지 않습니다.** 임의의 키로 짝을 맞추면
> 엉뚱한 거래의 실적이 차감되어 달성률이 잘못 계산됩니다.

# Q1. 대금 지급일 (W-1) 🔴 최우선

> **제공해 주신 파일의 `신고기준일`, `기표일자`, `결의일자` 중
> 실제 **대금 지급이 완료된 날짜**를 나타내는 값은 무엇입니까?
> 혹시 실제 지급일이 이 파일에는 포함되어 있지 않습니까?**

**왜 필요한가**: 중소기업·여성기업·장애인기업 등 대부분의 정책은 **지급일**을 기준으로
해당 연도 실적 여부와 인증 유효기간을 판정합니다. 기준일이 틀리면 **모든 정책 실적이 틀립니다.**

**샘플에서 확인된 상황**

| 항목 | 값 |
|---|---|
| `기표일자` 채움률 | 매입행의 **88.8%** (11.2% 는 비어 있음) |
| `기표일자` − `신고기준일` | 최소 **−5일**, 최대 32일, 평균 7.31일 |
| 날짜 역전(기표일자가 더 빠름) | **19건** |
| `결의일자` − `신고기준일` | 평균 0.84일 (84%가 같은 날) |
| `발행일` | `신고기준일`과 **100% 동일** |

→ `기표일자`를 지급일로 단정할 수 없어 **매핑하지 않았습니다.**

# Q2. 계약일 (W-2) 🔴 최우선

> **계약일은 어디에서 제공받을 수 있습니까?
> 현재 매입매출장 파일에 계약일 컬럼이 없는 것이 맞습니까?
> 별도의 계약 관리 데이터(시스템 또는 파일)가 존재합니까?**

**왜 필요한가**: **창업기업** 정책은 지급일이 아니라 **계약일**을 기준으로 판정하도록
설계되어 있어, 계약일이 없으면 창업기업 실적을 계산할 수 없습니다.

**샘플에서 확인된 상황**: 샘플의 **88개 컬럼 전체를 확인했으나 계약 관련 날짜가 없습니다.**
실제 운영데이터나 별도 계약 데이터에 존재할 수 있어 확인을 요청드립니다.

**참고**: "창업기업은 계약일 기준"은 현재 **프로젝트 설계**이며, 제공된 정부권장정책
자료에서 확인된 공식 기준은 아닙니다. 이 부분도 함께 확인이 필요합니다.

# Q3. 구매금액 기준 (W-3) 🔴 최우선

> **우선구매 실적 계산에 사용하는 구매금액은
> `공급가액`(부가세 제외)입니까, `계`(부가세 포함)입니까?**

**왜 필요한가**: 달성률의 분자·분모가 모두 이 금액으로 계산되므로, 기준이 다르면
달성률이 그대로 달라집니다.

**샘플에서 확인된 상황** (매입 597건 기준)

| 기준 | 금액 |
|---|---|
| `공급가액` (부가세 제외) | **4,277,205,517원** |
| `계` (부가세 포함) | **4,694,731,303원** |
| **차이** | **417,525,786원 (약 8.9%)** |

→ 어느 쪽도 임의로 선택하지 않았습니다.
(참고: `공급가액 + 세액 = 계` 관계는 2,903건 전부 성립합니다)

# Q4. 음수 거래 (W-4) 🔴 최우선

> **금액이 음수로 기록된 거래는 취소 / 감액 / 정정 중 무엇을 의미합니까?
> 우선구매 실적 계산에서는 어떻게 처리해야 합니까?
> (예: 원거래에서 차감 / 별도 집계 / 계산 제외)
> 그리고 음수 거래와 원래 거래를 연결할 수 있는 번호가 별도로 존재합니까?**

**왜 필요한가**: 처리 방식에 따라 정책 실적 금액이 달라집니다. 의미를 모른 채
자동으로 상계하면 **실적이 잘못 차감될 수 있어** 어떤 처리도 하지 않고 있습니다.

**샘플에서 확인된 상황**

| 항목 | 값 |
|---|---|
| 음수 매입 거래 | **34건 (매입의 5.70%)** |
| 음수 매입 합계 | **−80,624,906원** |
| 전체(매출 포함) 음수 | 125건 (4.31%) |
| 적요 | 취소·반품·정정을 뜻하는 문구 **없음** (예: `교육비`, `현수막`, `게시대현수막`) |
| 예산과목 | 음수 125건 **전부 비어 있음** |
| `기표일자` | 음수 125건 **전부 비어 있음** |
| `기표번호`·`결의번호`·`LN_SQ`·`GRP_NB` | 음수 125건 **전부 0** |

**자동 상계가 불가능한 이유**: 원거래를 가리키는 번호가 없고, 금액만으로 짝을 맞추면
**같은 금액이 중복**되어(예: `−132,000` 2건, `−200,000` 2건) 어느 거래에 대응하는지
결정할 수 없습니다.

# Q5. 공사 / 용역 / 물품 구분 (W-6) 🔴 최우선

> **원본 데이터에 공사 / 용역 / 물품 구분값을 포함해 제공해 주실 수 있습니까?
> 별도 시스템이나 다른 파일에 해당 구분값이 존재합니까?
> 없다면, 기관에서 사용하는 **공식 분류 규칙**이 있습니까?**
> (예: 예산과목 `외주용역비` → 용역, `소모성물품구입비` → 물품 등)

**왜 필요한가**: **여성기업** 정책은 구매유형에 따라 목표율이 다른 것으로 파악되어,
공사/용역/물품 구분 없이는 계산할 수 없습니다.

**샘플에서 확인된 상황**

| 항목 | 값 |
|---|---|
| 명시적 구분 컬럼 | 88개 컬럼 중 **없음** |
| 매입행 중 공사·용역·물품 **키워드가 전혀 없는 행** | **426건 (71.4%)** |
| `예산과목` 결측(매입행) | **15.4%** |
| 분류가 애매한 항목 | `임차료`(142건, 최다) · `통신비` · `수도광열비` · `각종수수료` |
| 한 행에 여러 성격 혼재 | 예: `토너구입비, 사무실청소비, 공기청정기, 정수기, 캡스` |

→ 적요 텍스트에서 키워드로 자동 분류하면 **71.4%가 미분류로 남고, 잘못 분류된 건은
달성률을 조용히 왜곡**하므로 자동 분류를 하지 않았습니다.
