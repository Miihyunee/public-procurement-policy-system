## 0. 이 문서가 하는 일

실거래 2,161건은 적재되었고 결의일자 기준 연도 귀속도 동작한다. 그런데
**정책별 분자가 전부 0** 이다. 왜 그런지, 무엇이 있어야 풀리는지를 적는다.

> ⛔ **이 문서는 인증 데이터 원천을 확정하지 않는다.** 고객이 답한 적 없는
> 사안이므로 임의로 정하지 않는다. 조사 결과와 **PM 이 내려야 할 결정 하나**
> 까지만 적는다.

> ⚠️ 원본 파일은 **읽기 전용**으로만 열었다. 실데이터를 저장소에 넣지 않으며,
> 거래처명·사업자등록번호를 이 문서에 옮겨 적지 않는다.

## 2. 지금 무엇이 비어 있는가 — **두 칸이 비어 있다**

실데이터를 적재한 DB 를 그대로 들여다본 결과다.

| 테이블 | 건수 | 적재 경로 |
|---|---|---|
| `purchase` (거래) | **2,161** | ✅ 표준 업로드 |
| `company` (기업) | **0** | ❌ **경로 자체가 없다** |
| `certification` (인증) | **0** | 수집기는 있으나 키 미발급 |

### 2.1 ⚠️ 기업 명단이 없다 — 이것이 먼저다

거래 2,161건 **전부**가 `company_id = NULL`(미매칭)이다. 기업 테이블이 비어
있기 때문이다.

그리고 **기업을 적재하는 경로가 시스템에 없다** — CLI 명령(`init` · `run` ·
`health`)에도, API 에도, 업로드 화면에도 없다. 기업 행을 만드는 코드는
저장소(`CompanyRepository.insert`)뿐이고 그것을 호출하는 업무 코드가 없다.

⚠️ **인증 API 키가 내일 발급되어도 이 상태로는 한 건도 저장되지 않는다.**
`CertificationSyncService.sync_one()` 은 사업자번호로 **기업을 먼저 찾고**,
없으면 `SKIP_COMPANY_NOT_FOUND` 으로 건너뛰기 때문이다.

```
API 키 발급  →  sync_one()  →  기업 조회  →  없음  →  건너뜀
                                    ↑
                          여기가 비어 있다
```

→ 그래서 **기업 명단과 인증 명단의 출처는 사실상 같은 하나의 결정**이다.

## 8. PM 이 내려야 할 결정 — **하나**

> **인증 정보(그리고 기업 명단)를 어디서 가져올 것인가?**

| 안 | 내용 | 필요한 것 |
|---|---|---|
| **(가)** | 인증 API 3종 발급을 기다린다 | 키 발급 + **기업 명단 적재 경로**(§2.1) |
| **(나)** | 원본 「작업」 시트를 원천으로 승인한다 | 아래 §8.1 의 읽는 규칙을 함께 확정 |
| **(다)** | 고객에게 기업·인증 명단을 별도로 받는다 | 요청·수령 |

### 8.1 (나)를 고르면 **함께 정해야 하는 것**

시트를 그대로 읽을 수 없기 때문이다. ⛔ 아래를 우리가 정하지 않았다.

1. **중소기업을 무엇으로 볼 것인가** — `업체규모` 의 어느 값까지인가.
   `N(소상공인)` · `중기업(간주기업)` 의 뜻은 무엇인가.
2. **`업체규모` 와 「중소기업 기간」이 어긋나는 80행**을 어느 쪽으로 읽는가.
3. **`#N/A`(1,710행)** 는 "인증 없음" 인가 "조회 실패" 인가.
4. **종료일이 없는 인증**(사회적기업 · 사회적협동조합)의 유효기간은 무엇인가.
5. **시트에 없는 80개 업체**(거래는 있음)를 어떻게 볼 것인가.
6. 사회적기업 · 사회적협동조합 · 장애인표준사업장은 **정책으로 등록되어 있지
   않다** — 시트에 값이 있다는 이유로 새 정책을 만들지 않았다(🟢 §0.12.1 단서).

⛔ **위 6개는 시트를 쓰기로 한 뒤에 답해야 하는 것이며, 지금 우리가 정하면
근거 없는 실적 숫자가 된다.**

| **③** | 「업체규모」 ↔ 「중소기업 기간」 불일치 80행 | 두 칸이 서로 다른 이야기를 한다(§3.3) | 중소기업 분자에서 최대 80행의 업체 |
| **④** | `#N/A` 는 인증 없음인가 확인 필요인가 | 1,710행에 `#N/A`(§3.2) | 실적에서 **빠지느냐** 확인 목록에 **남느냐** |
| **⑤** | 종료일 없는 인증의 유효기간 | 사회적기업·사회적협동조합에 시작일만 있다(§3.2) | 결의일자와 대조할 **구간 자체**가 만들어지는지 |
| **⑥** | 시트에 없는 80개 업체 | 거래는 있는데 시트에 없다(§4 ④) | 그 업체 거래가 **인증 없음으로 확정**되는지 |
| **⑦** | 사회적기업 등 3종을 집계할 것인가 | 시트에 값은 있으나 **정책으로 등록되어 있지 않다** | 정책 신규 등록 여부 + 목표 비율 |
| **📎** | 목표 비율 | 전 정책 미설정(D-004 — 임의 입력 금지) | 달성률 산출 가능 여부 |

⚠️ **①이 ②~⑦ 의 전제다.** ①이 *"사용 불가 · 명단을 따로 주겠다"* 로 오면
②~⑥ 은 그 명단의 모양을 보고 다시 정리해야 하므로 지금 답할 필요가 없다.

| ③ 불일치 80행 | 〃 |
| ④ `#N/A` | 인증을 **만들지 않거나**, 확인 목록으로 남긴다 |
