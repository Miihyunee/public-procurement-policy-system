## 3. 최종 수치 검증 원칙

### 3.1 항등식

```
원본 행 수 = 적재 행 수 + 미적재 행 수
```

⛔ 이것이 맞지 않으면 **다른 숫자를 볼 필요가 없다.** 먼저 여기부터 본다.

### 3.2 계산으로 가는 순서

```
전체 적재 데이터
      ↓  ACTIVE 배치만
      ↓  실적 제외
      ↓  기간 조건
분모
      ↓  기업 매칭
      ↓  정책 조건
      ↓  인증 유효기간 (정책별 판정 기준일)
분자
      ↓
구매비율 = 분자 ÷ 분모 × 100
달성률   = 구매비율 ÷ 목표율 × 100
```

이 순서가 코드와 같은지 확인한다 —
`database/purchase_repository.py` `find_for_calculation()` →
`calculators/procurement_achievement.py`.

### 3.3 손계산 대조

달성률은 **시스템 표시값과 독립적으로 계산한 값**을 맞대어 본다.
⚠️ 구매비율은 응답에 없으므로 분자 ÷ 분모로 직접 구한다.

⛔ 실데이터에서 나온 숫자는 **검증을 마친 뒤에만** 최종 결과로 기록한다.
