# 설치 안내 (고객 전달용)

공공구매정책관리시스템을 설치하고 처음 실행하는 방법입니다.

Python 이나 Node.js 를 따로 설치하지 않아도 됩니다. 프로그램 안에 필요한 것이
모두 들어 있습니다.

---

## 1. 설치파일 실행

전달받은 `공공구매정책관리시스템 Setup 0.1.0.exe` 를 두 번 누릅니다.

설치 중에 **「모든 사용자」** 와 **「나만 사용」** 중 하나를 고르는 화면이
나옵니다. 어느 쪽을 골라도 됩니다.

- 모든 사용자 — 관리자 권한이 필요합니다
- 나만 사용 — 권한 없이 설치됩니다

## 2. Windows 보안 경고가 나올 경우

이 프로그램에는 코드 서명 인증서를 붙이지 않았습니다. 그래서 Windows 가
처음 보는 프로그램이라며 파란 경고창을 띄울 수 있습니다.

```
Windows의 PC 보호
Microsoft Defender SmartScreen에서 인식할 수 없는 앱의
시작을 차단했습니다.
```

이때는 **「추가 정보」** 를 누르고, 아래에 나타나는 **「실행」** 을 누르면
됩니다.

> ⚠️ 이 창이 뜨지 않고 바로 설치가 시작될 수도 있습니다. 그래도 정상입니다.
> 같은 파일을 이미 한 번 실행한 적이 있거나, 기관의 보안 설정에 따라
> 다릅니다.

## 3. 설치 완료 후 실행

바탕화면의 **공공구매정책관리시스템** 아이콘을 두 번 누릅니다.
시작 메뉴에서도 찾을 수 있습니다.

## 4. 최초 실행 확인

창이 열리고 대시보드 화면이 보이면 정상입니다.

프로그램을 처음 켜면 자료를 담을 데이터베이스가 아래 자리에 자동으로
만들어집니다.

```
%APPDATA%\procurement-desktop\database\procurement.db
```

주소창에 `%APPDATA%\procurement-desktop` 을 붙여 넣으면 그 폴더가 열립니다.

> ⭐ 이 자리는 **프로그램을 지워도 남습니다.** 새 버전을 다시 설치해도 그동안
> 넣으신 자료가 그대로 있습니다.

창을 처음 열 때 화면이 잠깐 비어 있을 수 있습니다. 프로그램이 내부에서
서버를 켜는 몇 초 동안입니다.

> ⭐ **사용자 매뉴얼은 프로그램 안에 들어 있습니다.** 화면 오른쪽 위의
> **「사용자 매뉴얼」** 을 누르면 PDF 를 내려받을 수 있습니다. 설치파일과
> 매뉴얼을 따로 챙기지 않으셔도 됩니다.

## 5. 문제가 생기면

아래 정보를 함께 알려 주시면 원인을 빨리 찾을 수 있습니다.

1. **어느 단계에서** 멈췄는지 — 설치 중 / 실행 직후 / 사용 중
2. **화면에 나온 메시지** — 화면을 그대로 사진 찍어 주셔도 됩니다
3. **Windows 버전** — `Windows 키 + R` → `winver` 입력 → 확인
4. 아래 폴더가 있는지, 그 안에 `procurement.db` 가 있는지

   ```
   %APPDATA%\procurement-desktop\database
   ```

5. 프로그램을 껐는데도 남아 있는 것이 있는지 — PowerShell 에서

   ```powershell
   Get-Process procurement -ErrorAction SilentlyContinue
   ```

   아무것도 안 나오면 정상입니다.

---

## 참고 — 프로그램을 지울 때

**설정 → 앱 → 설치된 앱** 에서 지웁니다.

지워도 `%APPDATA%\procurement-desktop` 안의 자료는 **남습니다.** 자료까지
완전히 없애시려면 그 폴더를 직접 지우셔야 합니다.

> ⛔ 프로그램을 지우기 전에 창을 먼저 닫아 주십시오. 켜 둔 채로 지우면
> 파일 일부가 남을 수 있습니다.
