# 1. 현재 데이터 사실 (실측)

## 1.1 원본 컬럼에 구매유형이 없다

원본 지출데이터의 컬럼: `번호` · `신고기준일` · `적요` · `거래처명` ·
`사업자번호` · `공급가액` · `세액` · `계` · `결의일자` · `예산과목`.

|---|---|

- 공사 / 용역 / 물품 각각의 **업무상 정의**

- 판정 근거가 **계약 형태 / 지출결의서 계약내용** 인지 **예산과목** 인지

### [개발 가능]

**❌ 없음.** 정의가 없으면 어떤 판정 로직도 근거를 갖지 못합니다.

> 실적 산정 시 구매유형 공사 / 용역 / 물품은 어떤 기준으로 구분합니까?
> 계약 형태나 지출결의서의 계약내용을 기준으로 구분합니까, 예산과목을 기준으로

## PT-2 (지시서 Q5-2) — 외주용역비 판정 기준 🔴 최우선

### [확정]

| 내용 | 근거 |
|---|---|

| 담당자 `세목유형관리` 메모에 외주용역비는 **`물품/용역/공사`** 세 유형 모두로 적혀 있다 | 분석문서 §4.3 |

| 외주용역비는 **자동분류 금지 목록**에 명시되어 있다 | `DECISIONS.md` §0.9.4 |

관찰된 적요 사례 (분석문서 §질문 2):

| 확정 유형 | 적요 예시 |
|---|---|
| 공사 | `매입축사 지장물 철거공사 선금` · `하도급 지킴이(선급금)` |
| 용역 | `2025년 하반기 인성검사 비용` · `화학물질 양성사업 파견 대행 용역(12월)` |

### [미확정]

- 외주용역비 중 **어떤 조건이면 공사** 인지
- 지시서가 열거한 각 성격의 분류 — 시설물 설치 / 시설물 보수 / 시설물 유지보수 /
  공사성 작업 / 단순 용역 / 점검·관리 용역
- 외주용역비에 **물품**이 들어갈 수 있는지 (담당자 메모에는 있으나 작업본 실측은 0건)

### [개발 가능]

**❌ 없음.** 이 항목이 금액의 62.3% 를 좌우하므로, 임의 규칙을 넣으면 달성률이
크게 왜곡됩니다.

> 시설물 설치 · 시설물 보수 · 시설물 유지보수 · 공사성 작업 · 단순 용역 ·

| **후보 추천과 최종 확정은 구조적으로 분리되어 있다** | `models/classification.py` 에 최종 유형 필드가 **의도적으로 없음** |
| 적요 정규화는 이미 구현·운영 사용 중 | `core/description_key.py` |

- `공사` · `공사비` · `보수공사` · `설치공사` 표현을 **공사 후보**로 삼아도 되는지
- `용역` · `위탁` · `운영` · `관리` · `점검` 표현을 **용역 후보**로 삼아도 되는지
- 두 낱말이 함께 든 적요(현재 배치 4건)를 어떻게 다룰지

### [개발 가능]

**△ 조건부.** 아키텍처(후보 ≠ 확정)는 이미 타입 수준에서 보장되어 있어, 답변이
오면 후보 생성기만 끼우면 됩니다. 다만 **어떤 낱말을 어떤 후보로 볼지**가
정해지기 전에는 만들지 않습니다.

### [확인 질문]

> 적요에 `공사` · `공사비` · `보수공사` · `설치공사` 등이 있으면 **공사 후보**로
> 추천해도 됩니까? 반대로 `용역` · `위탁` · `운영` · `관리` · `점검` 등이 있으면
> **용역 후보**로 추천해도 됩니까?
> (추천일 뿐이며 확정은 담당자가 합니다.)
