# 2. 기존 수작업 프로세스 (실측으로 재구성)

```text
원본 Excel (10컬럼)
      │
      ├─(1) 삭제표기 시트 복사 → 제외·상계 대상을 배경색으로 표시
      │        · 연한색  252행 = 상계쌍 126쌍
      │        · 다른색    6행 = 0원·반환금 등
      │
      ├─(2) 남은 행을 작업 시트로 옮김
      │
      ├─(3) 🔴 각 거래의 지출결의서를 열어 실제 내용 확인  ← 원본에 없는 정보
      │
      ├─(4) 구분(물품/용역/공사) 입력
      │        · 세목유형관리 메모를 기준으로 삼되, 예외를 개별 판단
      │
      └─(5) 사업자번호로 외부 인증 명단 조회(VLOOKUP) → 인증 컬럼 채움
```

(3) 은 파일에 흔적이 남지 않는다. 그러나 §5·§6 의 실측 결과는 **원본 정보만으로는
분류가 불가능**함을 보이므로, (3) 이 존재했다는 PM 설명과 부합한다.

## 3.3 제외·상계 처리 — `삭제표기` 시트

표시는 **셀 배경색**으로만 되어 있다(취소선 0건, 비고 컬럼은 4건뿐).

| 색 | 행 수 | 내용 |
|---|---|---|
| 연한색 A | **252행** | 음수 126 + 양수 126 → **금액 합계 정확히 0** |
| 색 B | 6행 | 0원 2건 · 음수 2건(반환금) · 기타 2건 |
| 색 없음 | 2,034행 | |

### ✅ 고객 확정 상계 규칙이 실데이터에서 100% 재현된다

연한색 A 의 음수 126건에 대해 **기업명 + 사업자등록번호 + 절대금액** 으로 짝을
찾은 결과:

```text
126 / 126 건 전부 짝이 맺혔다
```

적요가 서로 달라도 맺힌다 — 우리 규칙은 적요를 보지 않기 때문이다.

| 거래처 | 금액 | 양수 적요 ↔ 음수 적요 |
|---|---|---|
| 수원상공회의소 | 2,025,870 | `1월 관리비` ↔ `1월 임대료` |
| 엘지전자(주) | 79,600 | `01/05 물품대 외` ↔ `2026년 01월 LG전자 가전/서비스` |
| (주)우창 | 771,540 | `환경보건` ↔ `수정발행` |

> ⚠️ **같은 날짜 상계쌍이 존재한다**(수원상공회의소 2026/01/02 양쪽). 현재 구현은
> 날짜가 같으면 `purchase_id` 순서로 "이전" 을 가린다. 실데이터에서는 양수가 앞
> 행이므로 맞게 동작하지만, **"같은 날짜일 때 무엇을 이전으로 볼 것인가" 는
> 고객 확인 대상**이다.

# 5. 🔴 원본 Excel 만으로 분류할 수 있는가 — 실측 결론

## 5.1 컬럼 조합별 "결정력" (겉보기)

같은 키인데 `구분` 이 갈리면 그 조합만으로는 판단할 수 없다.

| 키 조합 | 고유키 | 모순키 | 모순행 | 겉보기 결정력 |
|---|---:|---:|---:|---:|
| 예산과목 | 12 | 5 | 888 | 49.1% |
| 적요 | 1,201 | 17 | 58 | 96.7% |
| 거래처명 | 495 | 16 | 155 | 91.1% |
| 예산과목+적요 | 1,232 | 1 | 3 | 99.8% |
| 예산과목+거래처명 | 552 | 3 | 10 | 99.4% |
| 적요+거래처명 | 1,407 | 0 | 0 | **100.0%** |

## 5.2 ⚠️ "100%" 는 규칙이 아니라 **암기**다

| 키 | 고유키 수 | 1번만 등장하는 키 |
|---|---:|---:|
| 적요 | 1,201 | 893 (74%) |
| 적요+거래처명 | 1,407 | **1,199 (85%)** |

한 번만 나오는 키는 **일관성을 검증할 기회 자체가 없다.** 자동으로 "모순 0" 이
된다. 게다가 적요는 재사용되는 값이 아니다.

- `숫자+월` 이 들어간 적요 **849건 (48%)** — 예: `기술지원팀 1월 출장 차량 주차비`
- 숫자가 들어간 적요 **1,098건 (62%)** — 예: `정수기렌탈(25년 12월)`

**다음 달 데이터에는 같은 적요가 거의 나오지 않는다.**

## 5.3 결정적 검증 — 앞 절반으로 뒤 절반을 맞출 수 있는가

데이터를 시간순 절반으로 나눠, 앞 절반에서 만든 표로 뒤 절반(872건)을 예측했다.

| 키 조합 | 예측 불가(미등장 키) | 예측 시도 | 적중 | **오답** |
|---|---:|---:|---:|---:|
| 예산과목 | 0건 (0%) | 872 | 784 | **88 (10.1%)** |
| 예산과목+거래처명 | 337건 (38%) | 535 | 532 | 3 |
| 적요+거래처명 | **831건 (95%)** | 41 | 41 | 0 |

### 결론

> **원본 Excel 만으로는 구매유형을 정확히 판단할 수 없다.**
>
> - 예산과목만 쓰면 전부 예측되지만 **10건 중 1건이 틀린다**
> - 적요+거래처명은 틀리지 않지만 **새 데이터의 95%를 판단하지 못한다**
> - 둘 사이 어떤 조합도 "전부 예측 + 정확" 을 동시에 달성하지 못한다

## 질문 3 — 적요만으로 판단할 수 있는가

**할 수 없다.**

## 질문 5 — 담당자가 지출결의서에서 본 핵심 정보는 무엇이었을까

**⚠️ 이 항목은 추측이므로 사실로 기록하지 않는다.** 확인된 것과 확인이 필요한
것을 나눈다.

### 확인된 것 (파일에 근거가 있음)

1. 담당자는 **거래처명 단위 예외**를 관리했다 — `콘텐츠브릿지`, `(주)한국인프라`,
   `호건코리아`, `주식회사 에쓰피케이` 가 메모에 이름으로 적혀 있다
2. 담당자는 **품목 단위 예외**를 관리했다 — `컴퓨터 등 임차`, `PC대여`,
   `태블릿 대여`, `커피머신`, `주차료`, `대관`, `식대`
3. 담당자는 **계약 성격**을 언급했다 — `용역 성격의 미계약건 삭제`
4. 같은 거래처·같은 적요라도 건별로 유형이 달라졌다

### 확인이 필요한 것 (고객 확인 대상)

1. 지출결의서의 **어느 항목**을 보았는가 (품목명? 계약서 첨부 여부? 계약 종류?)
2. `물품 / 용역 / 공사` 의 판단 기준은 무엇인가 (법령? 내부 지침? 관례?)
3. 소프트웨어 라이선스처럼 **물품과 용역의 경계**에 있는 건은 무엇으로 보는가
   — 같은 거래처의 CAD 구매가 물품·용역 양쪽에 있다
4. 위 예외들이 **개인 판단**인가 **기관 규정**인가

# 8. 개발 제안 (PM 승인 전 구현하지 않음)

## 8.1 하면 안 되는 것

⛔ **예산과목 → 구매유형 자동 분류를 구현하지 않는다.**
오답률 10.1% 는 법정 실적 수치에 그대로 반영된다.

⛔ **작업본의 `구분` 값을 학습 데이터로 삼아 규칙을 역산하지 않는다.**
§5.2 에서 보였듯 겉보기 정확도는 암기에서 온다.

## 8.2 제안 — 자동화 대신 **판단을 돕는 도구**

| 안 | 내용 | 근거 |
|---|---|---|
| **A** | 업로드 양식에 `구분` 컬럼 추가, 담당자가 직접 입력 | 지금도 사람이 판단 중 |
| **B** | A + 단일 유형 7종은 **기본값 제안**(수정 가능), 혼재 5종은 빈칸으로 두고 입력 요구 | 절반은 손이 덜 가고, 틀릴 수 있는 절반은 사람이 본다 |
| **C** | 지출결의서 데이터를 시스템이 함께 받는다 | 근본 해결. 다만 데이터 확보 경로가 미확인 |

> **B 를 권장한다.** 단, "기본값 제안" 도 이번 데이터 12종 관찰에 기반하므로
> **고객이 확정해 준 매핑만** 제안값으로 쓰고, 나머지는 빈칸으로 두어야 한다.

## 8.3 먼저 물어봐야 할 것

1. 지출결의서 데이터를 **파일로 받을 수 있는가** (있다면 §7-B 가 A 로 이동)
2. 물품/용역/공사 판단의 **공식 기준 문서**가 있는가
3. `구분` 을 담당자가 시스템에 직접 입력하는 방식이 업무상 수용 가능한가

# 8.5 🔴 지출결의서 연결 가능성 조사 (2026-08-18 추가)
